# EFD (Eye Fatigue Detection) v2.0.0 Windows 桌面端測試指南

本軟體為 **EFD 眼睛特徵提取與即時疲勞監控研究系統** 之 Windows 原生免安裝綠色版本。

---

## 一、 快速啟動方式

1. 請先將壓縮包 **完整解壓縮** 至您指定的資料夾（例如桌面或磁碟機根目錄）。
2. 在解壓後的資料夾中，直接雙擊 **`EFD.exe`** 或 **`啟動 EFD.bat`** 即可立即開啟系統。
3. （可選）雙擊 **`建立桌面捷徑.bat`**，系統將自動於您的 Windows 桌面上建立專屬捷徑。

---

## 二、 系統需求與注意事項

1. **作業系統**：Windows 10 / Windows 11 (64 位元)。
2. **硬體需求**：筆記型電腦內建視訊鏡頭或一般 USB 外接網路攝影機。
3. **攝影機存取權限**：
   - 若開啟後提示找不到攝影機，請至 Windows「設定」->「隱私權與安全性」->「相機」，確認已開啟「允許傳統型應用程式存取相機」。
   - 若電腦未接攝影機，系統亦內建高品質模擬驅動模式，確保所有功能介面與推論管線皆可完整體驗。
4. **綠色免安裝**：
   - 本套件已自帶所需之微軟 C++ 執行庫，無需額外安裝任何軟體或 Visual Studio。

## 三、 測試流程指引 (九大核心階段)

1. **階段 1 歡迎介面**：
   - 滿版薄荷綠背景與「資產 10」官方 Logo，點擊 **「進入測試說明」**。
2. **階段 2 特徵提取說明**：
   - 觀看黃點 4 秒平滑演示預覽，確認攝影機串流狀態，點擊 **「我準備好了，開始校準」**。
3. **階段 3 倒數計時等待**：
   - 保持臉部正對螢幕，進行 3 -> 2 -> 1 動態倒數。
4. **階段 4 多點動態眼動特徵提取**：
   - 視窗轉入深黑高對比介面，請注視動態黃點採樣軌跡（中心 -> 左上 -> 右上 -> 右下 -> 左下），下方金色進度條達 100% 後自動計算個人基準。
5. **階段 5 基準校準完成結果提示**：
   - 檢視個人常態睜眼 EAR、自適應閉眼判定閾值、特徵採樣品質等。
   - 可點擊 **「進入即時疲勞監控中心」** 觀看即時推論，或點擊 **「關閉系統介面」** 轉入背景靜默監控。
6. **階段 6 即時眼睛疲勞監控中心**：
   - 實時呈現生理狀態標籤與 4 大核心跳動指標（雙眼 EAR、PERCLOS 閉眼比、MSE 複雜度、綜合疲勞分數）。
   - 按鈕僅保留 **「進入設定介面」** 與 **「關閉系統介面」**。
7. **階段 7 系統設定介面**：
   - 僅保留 **「提示靈敏度（點擊切換循環）」**、**「重設眼動監測」** 及 **「返回監控中心」**（已徹底刪除多餘的手動警報按鈕）。
8. **階段 8 施測結束後測介面**：
   - 顯示 14 天時序安全封存憑證，點擊 **「前往填寫後測問卷 (Google 表單)」**，系統將自動開啟瀏覽器跳轉至後測問卷網址：
     `https://forms.gle/y5f1jTnrrtsxz65G9`
9. **階段 9 問卷提交完成**：
   - 提示科研授權憑證，點擊 **「完成並退出系統」**。

## 四、 背景靜默監控與超標警報說明

- 當您點擊 **「關閉系統介面」** 後，視窗將隱藏至 Windows 右下角系統托盤（工作列右下角圖示）。
- 系統在背景執行時**完全靜默無感**，不干擾您的正常作業。
- **僅於用眼疲勞分數超標（疲勞值 $\ge 65.0$ 或嚴重警報）時**，系統托盤才會彈出 Windows 原生氣泡提醒：「**你的眼睛處於疲勞狀態，請適當休息**」。
- 您可隨時在系統托盤圖示上連按兩下或按右鍵，即可隨時喚回主視窗。
