# EFD Android 版使用說明書

2026-11-04 更新 · 適用 EFD v2.2.0 Android 版

## 1. 簡介

EFD 是一個在手機背景執行的眼睛疲勞偵測研究 App：用前鏡頭分析眼睛開合，判定眼睛疲勞時提醒你休息。本說明書適用於 **EFD v2.2.0 Android 版**，研究期間共 14 天。

| 項目 | 需求 |
| --- | --- |
| 系統版本 | Android 7.0 以上 |
| 手機 | 一般手機使用 arm64 版（檔名含 `arm64-v8a`），32 位元舊手機請向研究人員索取另一版；已在 Samsung A71、OPPO Reno13 Pro 上完成測試 |
| 網路 | 每天晚上 21:00 上傳數值資料時需要連線 |
| 權限 | 相機、通知 |

鏡頭畫面只在手機的記憶體中分析，不會儲存或上傳；上傳到研究試算表的只有疲勞相關的數值。通知列會持續顯示 EFD 正在偵測，這是 Android 對背景使用鏡頭的規定。

## 2. 安裝

安裝檔由研究人員提供，不在 Google Play 上。

1. 在手機上開啟研究人員提供的 EFD 安裝檔（`.apk`）。
2. 若出現「基於安全性考量，系統不允許安裝」，點「設定」並開啟「允許安裝未知應用程式」，再返回安裝。
3. 安裝完成後開啟 EFD，依提示**允許相機**與**允許通知**。
4. 第一次進入監控中心時，App 會依序跳出兩個說明：
    1. 電池最佳化：請把 EFD 設為「不最佳化」或「不受限制」。
    2. 通知與背景執行設定：依畫面上你的手機廠牌說明，開啟「提醒彈出」與「背景執行」（例如三星：通知彈出式樣式選「詳細」；OPPO：耗電管理 → 完全允許背景行為）。
5. 若第 4 步選了「稍後」，可到 EFD「系統參數設定 → 通知與背景執行設定」再次查看並完成。

背景執行與提醒彈出的設定很重要：沒有設定時，部分手機會在你劃掉 App 後關閉偵測（當天就不會有資料），或提醒只會靜靜出現在通知欄、看不到數字按鈕。

## 3. 第一次使用流程

第一次開啟需要分組與校準；完成後，之後每次開啟都會直接進入監控中心。校準時請**把手機拿到和眼睛同高**。

1. **歡迎畫面**：點「進入測驗說明」。
2. **選擇組別**：請由研究人員依分配表點「A 組」或「B 組」，再按「確認」。**選定後無法更改**，選錯請聯絡研究人員。
    - A 組：第 1～7 天只記錄數據，第 8～14 天顯示疲勞提醒。
    - B 組：第 1～7 天顯示疲勞提醒，第 8～14 天只記錄數據。
3. **測驗說明**：閱讀注意事項，點「我準備好了，開始校準」。
4. **校準**：臉正對手機，眼睛跟著畫面上的黃點移動，正常眨眼即可，完成後會自動跳到結果。
5. **校準完成**：點「進入即時眼動監控中心」；若顯示校準失敗，調整姿勢與光線後點「重新校準」。
6. **監控中心**：可以看到鏡頭畫面與四個數值。之後直接回到主畫面使用手機即可，EFD 會在背景偵測。

## 4. 日常使用

平常照常使用手機即可：EFD 在背景偵測，只有判定眼睛疲勞時才會打擾你。

### 4.1 背景偵測

- 通知列會持續顯示 EFD 正在偵測，請不要關閉這個通知。
- 螢幕關閉時鏡頭會自動暫停，解鎖後自動恢復。
- 在監控中心點「背景運行模式」可回到主畫面，偵測繼續進行。

### 4.2 疲勞提醒與眼睛疲勞自評

- 疲勞分數（0～100）達 65 分並持續 5 秒時會提醒。分數由閉眼時間比例、眨眼變慢、長時間閉眼等跡象累加，例如明顯閉眼約半分鐘，或眼睛沉重、頻繁慢眨眼一段時間。
- 提醒時會詢問一題「你現在眼睛疲勞的程度？」，0 = 完全不累、10 = 非常疲勞，**點一下數字就完成**。請依當下的感覺快速作答。
    - EFD 開在畫面上時：直接跳出對話框。不方便回答可點「略過」；30 秒沒有作答也會記為略過。
    - EFD 在背景時：以通知提醒，**通知上直接有 0～10 按鈕**，不必打開 EFD。劃掉通知記為略過；三星手機若彈出式樣式為「簡短」，請下拉通知欄作答。
- 沒有在通知上作答時，30 分鐘內打開 EFD 會補問「稍早的疲勞提醒：當時眼睛有多疲勞？」；超過 30 分鐘就不再詢問。
- 若你的組別本週是「只記錄數據」，程式照常偵測，但不會提醒。這是正常的。

### 4.3 提醒之後：20/5/5 規則

1. 提醒後 20 分鐘內不會再提醒，這段時間鏡頭關閉以節省電力。
2. 之後每 5 分鐘快速檢查一次（只在最後 1 分鐘開鏡頭），仍然疲勞才會再提醒。
3. 離開手機滿 5 分鐘視為已休息，回到一般偵測。

### 4.4 監控中心與設定頁

**監控中心的四個數值**：雙眼 EAR（眼睛開合程度）、閉眼比 PERCLOS、複雜度 CI、綜合疲勞分數（0～100）。只供參考，不需要去調整。

**設定頁**（監控中心 → 系統參數設定）：

| 項目 | 說明 |
| --- | --- |
| 提示靈敏度 | 低 / 標準 / 高；未經研究人員指示請維持「標準」 |
| 通知與背景執行設定 | 依手機廠牌設定提醒彈出、自動啟動與電池不受限制 |
| 重新校準眼動基準 | 換了使用環境、光線或配戴眼鏡時使用 |
| 關於與第三方授權 | 隱私說明與開放原始碼元件授權 |

## 5. 資料上傳與第 14 天後測問卷

### 5.1 每晚自動上傳

資料每天晚上 21:00 自動上傳，不需要手動操作。

- 上傳內容只有數值：每分鐘的疲勞摘要、每日統計、你回答的眼睛疲勞分數，以及匿名的受試者代碼。
- 21:00 時沒有網路或手機關機也沒關係：上傳失敗會在 10 分鐘後重試，隔天開啟時也會自動補傳。
- 研究期間請不要解除安裝 EFD 或「清除資料」，尚未上傳的資料、組別與校準都存在 App 裡。

### 5.2 第 14 天

1. App 會自動進入「施測結束」畫面。
2. 點「前往填寫後測問卷 (Google 表單)」完成問卷：https://forms.gle/y5f1jTnrrtsxz65G9
3. 填寫完成後，畫面會顯示完成憑證，請依研究人員指示提供。
4. 研究結束後，到手機「設定 → 應用程式 → EFD → 解除安裝」即可移除。

## 6. 注意事項

最重要的一點：**使用手機時盡量把手機拿到和眼睛同高**。手機拿得很低、鏡頭由下往上拍時，「閉眼」和「低頭看手機」在畫面上幾乎分不出來，會影響判定。

### 6.1 姿勢與光線

- 整張臉在前鏡頭畫面內，不要用手指或手機殼擋住前鏡頭。
- 保持光線充足；在全暗的房間或強烈背光下可能偵測不到臉。
- 躺著、側躺使用時仍可偵測，但臉要在畫面內。

### 6.2 電量與效能

- 螢幕開著時前鏡頭會持續分析，比平常多耗一些電；螢幕關閉時鏡頭停止，幾乎不耗電。
- 沒有偵測到臉時（例如手機平放在桌上），程式會先降低分析頻率；超過 1 分鐘仍沒看到臉，鏡頭會改成短暫開啟、暫停輪流檢查，你回到鏡頭前約 15 秒內就會恢復偵測。這段時間狀態列的鏡頭使用標示會時有時無，這是正常的。
- 同時玩大型遊戲時手機可能較熱；若明顯發熱或耗電異常，請告訴研究人員。

### 6.3 隱私

- 鏡頭畫面不會儲存、不會上傳，也沒有人能從遠端看到。
- 上傳的是匿名代碼與數值，不含你的姓名或影像。
- 使用其他需要鏡頭的 App（拍照、視訊）時，EFD 會暫時無法偵測，結束後會恢復。

### 6.4 請不要

- 關閉 EFD 的常駐通知，或在「應用程式資訊」中「強制停止」。
- 研究期間解除安裝或清除 App 資料。
- 把 EFD 的相機或通知權限關掉。

## 7. 常見問題

| 狀況 | 處理方式 |
| --- | --- |
| 監控中心顯示「未偵測到臉」 | 讓整張臉入鏡、檢查光線；仍無法偵測請聯絡研究人員，說明手機型號與發生時間 |
| 很久沒有提醒 | 正常：只有判定疲勞時才提醒；「只記錄數據」那一週不會提醒 |
| 提醒沒有彈出，或看不到數字按鈕 | 到「系統參數設定 → 通知與背景執行設定」依廠牌說明開啟提醒彈出 |
| 收到「EFD 疲勞偵測已停止」通知 | 點一下通知重新開始，再檢查「通知與背景執行設定」 |
| 重新開機後收到「點此開始今日偵測」 | 點一下即可（Android 14 以上不允許開機自動開鏡頭） |
| 安裝時顯示「與現有套件衝突」 | 手機上裝過簽章不同的測試版，請聯絡研究人員協助（解除安裝會刪除手機上的資料） |
| 選錯組別 | 聯絡研究人員，App 內無法自行更改 |
| 其他問題 | 聯絡研究人員，說明手機型號、發生時間與畫面上的文字 |
