# EFD Windows 版使用說明書

2026-11-05 更新 · 適用 EFD v2.3.0 Windows 版

## 1. 簡介

EFD 是一套在電腦背景執行的眼睛疲勞偵測研究軟體：透過電腦鏡頭分析眼睛開合，判定眼睛疲勞時提醒你休息。本說明書適用於 **EFD v2.3.0 Windows 版**，研究期間共 14 天。

| 項目 | 需求 |
| --- | --- |
| 作業系統 | Windows 10 或 Windows 11（64 位元） |
| 鏡頭 | 筆電內建鏡頭或 USB 網路攝影機 |
| 網路 | 每天晚上 21:00 上傳數值資料時需要連線 |
| 其他軟體 | 不需要，安裝包已內含所需的執行元件 |

鏡頭畫面只在你的電腦記憶體中分析，不會儲存或上傳；上傳到研究試算表的只有疲勞相關的數值。

## 2. 安裝

不需要安裝，解壓縮後就能使用。

1. 對 `EFD-v2.3.0-Windows.zip` 按右鍵，選「全部解壓縮」，放到桌面或任何你找得到的位置。
2. 解壓後會得到一個 **`EFD-v2.3.0-Windows`** 資料夾，所有程式檔案都在裡面，不需要另外建立資料夾。
3. 打開這個資料夾，雙擊 **`EFD.exe`** 或 **`啟動 EFD.bat`** 開啟程式。
4. （建議）雙擊 **`建立桌面捷徑.bat`**，之後從桌面捷徑開啟。
5. （建議）雙擊 **`啟用開機自動啟動.bat`**，之後電腦開機登入時 EFD 會自動在背景啟動（不會彈出主視窗），不會漏記開啟。

**第一次開啟時若出現「Windows 已保護您的電腦」**：點「其他資訊」→「仍要執行」。這是因為程式沒有商用數位簽章，不是病毒。

**找不到鏡頭時**：到 Windows「設定 → 隱私權與安全性 → 相機」，開啟「允許傳統型應用程式存取相機」。

| 資料夾內的檔案 | 用途 |
| --- | --- |
| `EFD.exe` | 主程式 |
| `models\`、`onnxruntime.dll` | 臉部特徵點模型，請勿刪除或移動 |
| `msvcp140.dll` 等 3 個 dll | 執行所需的微軟元件 |
| `assets\`、`design\` | 介面圖片 |
| `licenses\` | 第三方元件授權文件 |
| `啟用 / 停用開機自動啟動.bat` | 開關開機自動啟動 |
| `使用說明.txt` | 簡易使用說明 |

## 3. 第一次使用流程

第一次開啟需要分組與校準；完成後，之後每次開啟都會直接進入監控。校準時請**臉正對螢幕**。

1. **歡迎畫面**：點「進入測驗說明」。
2. **選擇組別**：請由研究人員依分配表選擇 A 組或 B 組。**選定後無法更改**，選錯請聯絡研究人員。
    - A 組：第 1～7 天只記錄數據，第 8～14 天顯示疲勞提醒。
    - B 組：第 1～7 天顯示疲勞提醒，第 8～14 天只記錄數據。
3. **測驗說明**：觀看黃點示範，確認畫面中看得到自己的臉，點「我準備好了，開始校準」。
4. **校準**：臉正對螢幕，等待 3、2、1 倒數後，眼睛跟著黃點移動（中心、左上、右上、右下、左下），正常眨眼即可，進度條到 100% 會自動完成。
5. **校準完成**：畫面顯示你的睜眼基準。校準失敗（例如臉沒有對準鏡頭）時會請你重新校準，請調整坐姿、開燈後再試一次。
6. **監控中心**：點「進入即時疲勞監控中心」查看數值，或點「關閉系統介面」讓程式在背景執行。

## 4. 日常使用

平常不需要操作：EFD 在背景偵測，只有判定眼睛疲勞時才會打擾你。

### 4.1 背景偵測

- 點「關閉系統介面」後，視窗會縮到右下角的系統托盤，程式仍繼續偵測。
- 已開啟開機自動啟動時，電腦開機登入後 EFD 會自動在背景開始偵測：右下角托盤出現 EFD 圖示並跳出「已在背景啟動」提示，筆電鏡頭的指示燈亮起就代表已開始。
- 在托盤圖示上連按兩下或按右鍵，可以叫回主視窗。
- 請不要從工作管理員結束 EFD，否則當天的資料會中斷。

### 4.2 疲勞提醒與眼睛疲勞自評

- 疲勞分數（0～100）達 65 分並持續 5 秒時，會跳出「你的眼睛處於疲勞狀態，請適當休息」。分數由多種跡象累加：眼皮下垂（眼睛睜得比平常小）、眼球移動變慢或變單調、眼部動作的複雜度下降、閉眼時間變長、眨眼變慢等。單一跡象不會提醒，兩項以上同時出現才會，不需要真的閉眼。
- 提醒時會詢問一題「你現在眼睛疲勞的程度？」，0 = 完全不累、10 = 非常疲勞，**點一下數字就完成**。請依當下的感覺快速作答。
- 不方便回答可以點「略過」；30 秒沒有作答也會記為略過。
- 若你的組別本週是「只記錄數據」，程式照常偵測，但不會跳出提醒。這是正常的。

### 4.3 提醒之後：20/5/5 規則

1. 提醒後 20 分鐘內不會再提醒，這段時間鏡頭會關閉以節省電力。
2. 之後每 5 分鐘快速檢查一次（只在最後 1 分鐘開鏡頭），仍然疲勞才會再提醒。
3. 離開座位滿 5 分鐘視為已休息，回到一般偵測。

### 4.4 監控中心與設定頁

**監控中心的四個數值**：雙眼 EAR（眼睛開合程度）、閉眼比 PERCLOS、複雜度 CI、綜合疲勞分數（0～100）。只供參考，不需要去調整。

**設定頁**（監控中心 → 進入設定介面）：

| 項目 | 說明 |
| --- | --- |
| 高靈敏度提醒 | 開啟後分數 58 持續 3 秒即提醒；未經研究人員指示請維持關閉 |
| 疲勞警報提示音 | 提醒時是否發出提示音 |
| 開機自動背景啟動 | 建議開啟；與 `啟用開機自動啟動.bat` 效果相同 |

## 5. 資料上傳與第 14 天後測問卷

### 5.1 每晚自動上傳

資料每天晚上 21:00 自動上傳，不需要手動操作。

- 上傳內容只有數值：每分鐘的疲勞摘要、每日統計、你回答的眼睛疲勞分數，以及匿名的受試者代碼。
- 21:00 時電腦關機或沒有網路也沒關係，下次開啟 EFD 時會自動補傳。
- 研究期間請不要刪除 `EFD-v2.3.0-Windows` 資料夾，尚未上傳的資料存在裡面。

### 5.2 第 14 天

1. 程式會自動進入「施測結束」畫面。
2. 點「前往填寫後測問卷 (Google 表單)」，瀏覽器會開啟問卷：https://forms.gle/y5f1jTnrrtsxz65G9
3. 填寫完成後，畫面會顯示完成憑證，請依研究人員指示提供。
4. 點「完成並退出系統」。
5. 研究結束後，先雙擊 `停用開機自動啟動.bat`，再刪除整個資料夾即可移除 EFD。

## 6. 注意事項

最重要的一點：**臉正對螢幕，讓鏡頭清楚看到你的雙眼**。偵測準不準，主要取決於鏡頭能不能清楚看到你的雙眼。

### 6.1 姿勢與光線

- 整張臉在鏡頭畫面內；不要用手或杯子擋住鏡頭。
- 保持光線充足，避免背後有強光（窗戶、檯燈）。
- 戴眼鏡可以使用；鏡片反光嚴重時，稍微調整螢幕角度。
- 換了使用環境、光線或座位後，可在監控中心點「重新偵測疲勞數據」重新校準。

### 6.2 電量與效能

- 鏡頭開著時程式會持續分析，筆電使用電池時會比平常多耗一些電。
- 沒有偵測到臉（例如離開座位）超過 10 秒，程式會降低分析頻率；回到鏡頭前會自動恢復。
- 若電腦明顯變慢、發熱或耗電異常，請告訴研究人員。

### 6.3 隱私

- 鏡頭畫面不會儲存、不會上傳，也沒有人能從遠端看到。
- 上傳的是匿名代碼與數值，不含你的姓名或影像。
- 使用視訊會議或其他需要鏡頭的程式時，鏡頭可能被佔用；EFD 會暫時沒有畫面，結束後會恢復。

### 6.4 請不要

- 從工作管理員結束 EFD。
- 研究期間刪除 `EFD-v2.3.0-Windows` 資料夾。
- 把 `EFD.exe` 單獨移出資料夾，或刪除 `models\`、`onnxruntime.dll`，否則會改用較不準確的備援偵測。想換位置時，請搬移整個資料夾，從新位置開啟一次 EFD（開機自動啟動會自動改到新位置），再重新執行「建立桌面捷徑」。

## 7. 常見問題

| 狀況 | 處理方式 |
| --- | --- |
| 畫面顯示「未偵測到臉」 | 調整坐姿讓整張臉入鏡，檢查光線與鏡頭權限；仍無法偵測請聯絡研究人員，說明電腦型號與發生時間 |
| 很久沒有提醒 | 正常：只有判定疲勞時才提醒；「只記錄數據」那一週不會提醒 |
| 開機後 EFD 沒有自動啟動 | 到設定頁確認「開機自動背景啟動」已開啟；搬移過資料夾或換過新版時，先從新位置手動開啟一次 EFD |
| 不小心關掉程式 | 重新從桌面捷徑開啟即可，分組與校準會保留 |
| 選錯組別 | 聯絡研究人員，程式內無法自行更改 |
| 其他問題 | 聯絡研究人員，說明發生時間與畫面上的文字 |
