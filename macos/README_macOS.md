# EFD (Eye Fatigue Detection) macOS 原生應用程式測試指南

本指南專為 **macOS 測試者** 提供，說明如何一鍵編譯、安裝、執行與測試 EFD 眼睛特徵提取與即時疲勞監控研究系統。

---

## 視覺與功能設計特色 (與 Windows / Android 端完全一致)

1. **視覺介面規範**：
   - **品牌識別**：歡迎介面置中呈現縮小 50% 之「資產 10」官方標誌。
   - **文字排版**：全面採用原生系統**粗體 (Bold)** 字體，消除所有前綴符號、表情貼、icon 及括號（【】）。
   - **按鈕質感**：全系統所有互動按鈕均套用 **20px 圓角邊框**、Hover 高亮反應與指針游標。
2. **九大核心階段流程**：
   - **階段 1 歡迎介面**：滿版薄荷綠風格，點擊進入測試說明。
   - **階段 2 特徵提取說明**：動態小黃點 DEMO 演示預覽、相機狀態監測條與三大指導方針卡片。
   - **階段 3 倒數計時等待**：3 -> 2 -> 1 動態脈衝倒數。
   - **階段 4 多點動態眼動特徵提取**：深黑背景高對比注視引導，五點黃點採樣軌跡與金色進度條。
   - **階段 5 基準校準完成結果提示**：個人化 EAR 基準、自適應閉眼閾值、採樣品質與 FPS 卡片。
   - **階段 6 即時眼睛疲勞監控中心**：生理狀態標籤、四大人體工學跳動指標（雙眼 EAR、PERCLOS 閉眼比、MSE 複雜度、綜合疲勞分數）。
   - **階段 7 系統設定介面**：僅保留「提示靈敏度（點擊切換）」、「重設眼動監測」與「返回監控中心」。
   - **階段 8 施測結束後測介面**：顯示 14 天時序安全封存憑證，點擊按鈕直接開啟 Google 表單（`https://forms.gle/y5f1jTnrrtsxz65G9`）。
   - **階段 9 問卷提交完成**：科研授權碼憑證與完成退出按鈕。
3. **背景靜默監控與精準警報**：
   - 於階段 5 或階段 6 點擊**「關閉系統介面」**後，主視窗將自動隱藏至 macOS 頂部選單列（Status Bar 狀態圓點）。
   - 背景運作時完全不干擾使用者工作，**僅於眼睛疲勞分數超標（疲勞值 $\ge 70.0$ 或嚴重警報）**時，才會透過 macOS 系統通知中心（User Notifications）彈出橫幅提醒：「你的眼睛處於疲勞狀態，請適當休息」。

## 測試者安裝與啟動方式

### 方法一：雙擊一鍵安裝啟動（最推薦，最簡單）

1. 將收到的 `EFD-v1.0.0-macOS.zip` 解壓縮。
2. 在 macOS Finder 中直接**連按兩下（雙擊）`Install-EFD.command`**。
3. 腳本會自動檢測 Apple Clang 編譯環境、編譯原生 Cocoa 二進制檔案、注入 Retina 高解析度圖示並直接啟動 `EFD.app`。
4. 腳本亦會主動詢問是否將應用程式安裝至 `/Applications` 系統目錄。

---

### 方法二：透過終端機腳本編譯與執行

開啟「終端機」(Terminal.app)，進入解壓後的目錄：

```bash
# 賦予腳本執行權限
chmod +x macos/*.sh macos/*.command Install-EFD.command

# 執行自動化建置 (自動產出 build/EFD.app)
bash macos/build_macos.sh

# 啟動應用程式
open build/EFD.app
```

---

### 方法三：打包為 macOS .dmg 安裝映像檔

若需要將軟體提供給其他無開發環境的 Mac 使用者測試，可直接生成標準 `.dmg` 映像檔：

```bash
bash macos/package_dmg.sh
```

- 生成檔案：`build/EFD-v1.0.0-macOS.dmg`
- 使用者雙擊打開後，只需將 `EFD.app` 圖示拖曳至 `Applications` 捷徑即可完成安裝！

## 系統需求與權限說明

1. **macOS 版本需求**：macOS 12.0 (Monterey) 或更新版本（支援 Apple Silicon M1/M2/M3/M4 及 Intel 架構）。
2. **攝影機存取權限**：
   - 首次啟動進行校準時，系統會跳出相機存取授權要求（`NSCameraUsageDescription`），請點選**「允許」**以利眼動特徵計算。
3. **通知授權**：
   - 當系統背景偵測到用眼疲勞超標時會發送提醒，請於通知提示中點選**「允許」**。
4. **macOS Gatekeeper 安全性提示排除**：
   - 若 macOS 提示「無法打開，因為 Apple 無法檢查是否包含惡意軟體」或未受信任的開發者：
     - **方法 A**：在系統「設定」->「隱私權與安全性」中，找到 EFD 並點選**「仍要打開」**。
     - **方法 B**：在終端機中執行指令解除隔離：
       ```bash
       xattr -dr com.apple.quarantine build/EFD.app
       ```
